# Domain and Custom ontologies processing scripts and result data

## Directories list

1. **Custom_Ontology** - The directory with constructed custom ontology
2. **Integr_custom_ont** - The directory with Python code and execution results for the Integration of constructed custom ontology and existing custom ontology using NLTK library.
3. **Integr_domain_ont** - The directory with Python code and execution results for the Integration of common ontology and domain ontology using NLTK library.
4. **SID_Ontology** - The directory with Python code and execution results for the TMF SID Ontology creation.
5. **source_data** - The directory with some source dataset for ontology processing.
4. **TMF_Ontology** - The directory with Python code and execution results for the Common Ontology creation based on TMF eTOM, SID and TAM models.
